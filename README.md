# 好好吃饭 · 一周健康带饭

一个单文件、零依赖的交互式周菜单规划器：为工作日的五天各排一套「主菜 + 蔬菜 + 主食 + 下午茶」，自动生成整周预制流程、合并采购清单和相关贴士。

## 打开

直接双击 `健康带饭周计划.html`，或访问 GitHub Pages：

```
https://melodyaanlin.github.io/healthy-meal-plan/
```

## 功能

- **四栏菜单**：主菜 / 蔬菜 / 主食 / 下午茶，每天独立下拉任选，或一键智能排周
- **智能排周算法**：拒绝采样 + 营养约束（主菜不重样、红肉 ≤ 2 天、鱼 ≥ 1 天、植物蛋白 ≥ 1 天、早上现做项不过载）
- **七套营养理论交集**：211 法则、地中海、DASH、MIND、WHO、美国膳食指南 2025–2030、中国居民膳食指南 2022
- **季节联动**：春/夏/秋/冬四套主题，应季食材优先标记，页面配色随季节换肤
- **预制流程自动分批**：周日做周一–周三，周四–周五冷冻或周三晚补货，含 15 分钟纠错窗口
- **采购清单**：全周合并去重、按人数缩放、库存标记、一键复制文本 / 打印存 PDF
- **应对偏差**：单日重抽、外食剔除、上下对调、清冰箱模式（按库存覆盖率评分排周）
- **忌口过滤**：牛羊肉 / 鱼虾海鲜 / 奶制品 / 鸡蛋，从下拉和排周池整体排除
- **本地持久化**：菜单、季节、冰箱勾选、忌口、人数自动存 localStorage，刷新不丢
